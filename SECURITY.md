# Security

## Reporting a problem

Email [contact@mru.space](mailto:contact@mru.space) with "security" in the
subject. Please do not open a public issue for a security problem. We reply by
email.

## Scope

This policy applies to every public repository in the mruspace organization
that has no SECURITY.md of its own. A repository with its own SECURITY.md
states its own scope. Mru Flight and Mru Field have one.

Mru software has no qualification evidence. Do not use it to control anything
that can cause harm.

## Supported versions

Only the latest release of each repository gets fixes.
