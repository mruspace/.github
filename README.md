# .github

Org profile and default community files for Mru.

- `profile/README.md`: the organization page at [github.com/mruspace](https://github.com/mruspace).
- `SECURITY.md`, `CONTRIBUTING.md`, `SUPPORT.md`: defaults for every public
  repository that has no file of its own.
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`: default issue
  and pull request templates.
